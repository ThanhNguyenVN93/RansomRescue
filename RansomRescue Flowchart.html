Bước 1 — Khởi động & Phát hiện
1.0
Khởi động RansomRescue.exe
  • Phát hiện nguồn: chạy từ USB hay download thẳng?
  • Nếu từ USB → DriveInfo.DriveType == Removable → đặt read-only + cảnh báo
  • Kiểm tra hash EXE (SHA-256) để đảm bảo file chưa bị mã hóa/thay thế
1.1
⚠️ Màn hình cảnh báo bắt buộc (hiện TRƯỚC tất cả)
  • Nếu máy ĐANG bị mã hóa (đèn HDD sáng, CPU/disk cao): TẮT NGUỒN NGAY
  • Nếu đã xong: có thể tiếp tục bình thường
  • Cách an toàn nhất: Boot vào Safe Mode trước khi chạy tool
  • Win 10/11: Shift+Restart → F4 | Win 7: F8 khi boot
  • 99% ransomware không có persistence trong Safe Mode
1.2
Load Database (Offline-first)
  • Main source: Scrape nomoreransom.org/en/decryption-tools.html (~170 decryptors)
  • Fallback 1: GitHub repo (db.json) — VN-specific families, cập nhật theo GH Actions khi NMR thay đổi
  • Fallback 2: Hard-coded ~30 families phổ biến VN nhất trong binary
  • Cache local: dùng nếu offline + cache còn <7 ngày
1.3
Hiện Form chính → Sẵn sàng
  • Hiển thị phiên bản DB đang dùng + thời gian cập nhật cuối
  • Cảnh báo nếu đang dùng fallback (offline/cache cũ)
Bước 2 — Quét thư mục
2.0
Người dùng bấm "Bắt đầu quét"
  • Cho phép chọn ổ / thư mục cụ thể hoặc quét toàn bộ
2.1
Quét tất cả thư mục — KHÔNG bỏ qua
  • Users/*: quét toàn bộ (extension + ransom note + header)
  • Windows, Program Files, System32: chỉ tìm ransom note, KHÔNG quét extension file hệ thống
  • Ổ khác, USB, NAS: quét đầy đủ
  • Thu thập: file bị đổi extension, ransom note, encrypted file mẫu
Bước 3–4 — Thu thập bằng chứng & Nhận diện
3.0
Thu thập bằng chứng
  • Lấy mẫu: extension bất thường, ransom note (.txt, .html, .hta), file header bytes
  • Kiểm tra registry: startup entries, shadow copies (vssadmin), wallpaper đã bị đổi
  • Ghi log: thời gian bị nhiễm ước tính (so sánh mtime file bình thường vs file bị mã hóa)
4.0
Nhận diện họ ransomware (Offline)
  • Match extension → db.json families
  • Match nội dung ransom note (keywords, email contact)
  • Match file header magic bytes
  • Kết quả: tên family + confidence score
Nhận diện được họ ransomware?
So khớp trong DB offline
Bước 5 — Phục hồi (luôn cần internet)
Đã biết family
5.1
Kiểm tra: có free decryptor không?
  • Tra db.json: decryptor_available field
  • Confirm online: kiểm tra URL NMR còn live không
Có decryptor?
5.1.1 — Có
✓
Hướng dẫn decrypt
  • Link tải decryptor (Emsisoft/Kaspersky/Avast/Bitdefender...)
  • Cần: 1 file gốc + 1 file đã mã hóa cùng loại
  • Cảnh báo: giữ lại file encrypted gốc trước khi decrypt
  • Nếu decryptor_conditional: giải thích điều kiện (vd: STOP/Djvu chỉ ~30% offline key)
5.1.2 — Không
✗
Chưa có decryptor
  • Lưu ransom note + file mẫu (encrypted) vào folder an toàn
  • Hướng dẫn gửi lên NMR Crypto Sheriff
  • Hướng dẫn liên hệ: Emsisoft, BleepingComputer forums
  • Nhắc: KHÔNG trả tiền chuộc, KHÔNG format ngay
Không biết / Chưa rõ

Bước 5.3 — Xử lý đặc biệt (hard-coded logic)
5.3
Khi nào kích hoạt? Khi db.json có trường special_handling
  • STOP/Djvu (stop_djvu_key_check): offline key check ~30%, submit pair lên Emsisoft → kết quả ngay
  • WannaCry (wannacry_ram_key): key có thể còn trong RAM → KHÔNG restart, dùng WannaKey/WanaKiwi
  • Petya/NotPetya (petya_mbr): MBR bị ghi đè → flow khác (MBR repair tool)
  • NAS Ransomware (nas_network): không quét local, hướng dẫn cách ly network ngay
  • Double-encrypted (double_encrypted): phát hiện 2 lớp mã hóa → cần decrypt 2 lần theo thứ tự
⚠ Điểm yếu do con người
W1
Cắm USB / tải về khi ransomware đang chạy admin
Ransomware chạy admin encrypt USB trong vài giây. Giảm thiểu: Safe Mode, tắt nguồn cứng trước. Không có tool nào tránh hoàn toàn được kịch bản này.
W2
Restart máy trước khi chạy tool
Mất RAM key của WannaCry và một số family khác. Tool phải cảnh báo rõ trước màn hình shutdown.
W3
Overwrite file gốc trước khi decrypt
Cần 1 file gốc chưa encrypt để submit key check. Hướng dẫn cần nổi bật: KHÔNG xóa file nào trước khi dùng tool.
W4
Trả tiền chuộc rồi mới dùng tool
Tiền đã mất nhưng thường không nhận được key. Tool cần hiển thị cảnh báo này ở màn hình đầu tiên.
W5
Không backup trước khi decrypt
Nếu decryptor lỗi hoặc sai key → mất luôn dữ liệu. Tool bắt buộc nhắc: backup encrypted file trước khi decrypt.
W6
STOP/Djvu online key (~70%): không có decryptor miễn phí
Emsisoft chỉ decrypt được nếu có offline key. Nếu online key: chỉ con đường duy nhất là chờ hoặc trả. Tool phải nói thẳng điều này.
